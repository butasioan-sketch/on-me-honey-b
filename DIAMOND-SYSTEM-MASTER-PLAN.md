## 📋 SKU-STRUKTUR (PERFEKTIONIERT)

### NAMING CONVENTION:

```
Format: [Kategorie][Nummer]-[Familie]-[Blank]

Beispiele:
A001 — T-Shirt — JN827 (James & Nicholson, 165g) ✅ LIVE
A002 — T-Shirt — PA4012 (PROACT, 130g) 🆕 NEU
A015 — Shorts — JN387 (James & Nicholson, 135g) ✅ LIVE
A016 — Shorts — PA1050 (PROACT, 180g) 🆕 NEU
B033 — Shopper — Canvas Heavy
C051 — Kissenbezug — BRILDOR 40×40cm 🆕 PILOT
E102 — Tasse 11oz — Weiß Keramik
```

### SKU-DATENBANK-SCHEMA:

```typescript
interface ProductSKU {
  // Identifikation
  sku: string;              // "A001", "C051"
  category: string;         // "A", "B", "C", ...
  family: string;           // "tshirt", "shorts", "pillow"
  
  // Blank-Spezifikation
  blank: {
    name: string;           // "James & Nicholson JN827"
    supplier: string;       // "James & Nicholson"
    articleNr: string;      // "JN827"
    material: string;       // "100% Polyester"
    weight: number;         // 165 (g/m²)
  };
  
  // Druck-Konfiguration
  print: {
    shape: PrintShape;      // "a4_flat", "cylinder_11oz", ...
    press: string;          // "VEVOR TL-LZ11001"
    maxArea: {
      width: number;        // 210 (mm)
      height: number;       // 297 (mm)
    };
    noPrintZones: string;   // "Schulter, Saum, Nähte"
  };
  
  // Foto & Overlay (NUR nach Messung!)
  photo: {
    front: string | null;   // "/products/001/front.png"
    back: string | null;    // "/products/001/back.png"
  };
  
  overlay: {
    front: Rect | null;     // { top: 26.3, left: 34.7, width: 30.9, height: 29.2 }
    back: Rect | null;      // Gemessen am Foto, KEINE Schätzung!
  };
  
  placement: {
    front: Rect | null;     // Wo Motiv im Atelier landet
    back: Rect | null;
  };
  
  // GLB 3D-Modell
  model3D: {
    family: string;         // "tshirt" → nutzt shirt-white-v2.glb
    glbPath: string;        // "/models/shirt-white-v2.glb"
    camera: CameraSettings; // Pro Familie kalibriert
  };
  
  // Partner & Pricing
  partner: {
    primary: string;        // "shirtigo" | "zick" | "spreadshirt"
    ek: number | null;      // EK in EUR (erst nach Recherche!)
    vk: number | null;      // VK in EUR (erst nach Kalkulation!)
  };
  
  // Status
  status: ProductStatus;    // "offen" | "anker" | "modell" | "pilot" | "pruefen" | "shop_live"
  
  // Metadaten
  meta: {
    displayName: {
      de: string;
      en: string;
      ro: string;
    };
    description: {
      de: string;
      en: string;
      ro: string;
    };
    tags: string[];
    sizes?: string[];       // ["S", "M", "L", "XL", "XXL"]
    colors?: string[];      // ["White", "Black", "Navy"] — nur Blank-Farben!
  };
}
```

```

                  ↓

                  ↓
5. pruefen      → 11-in-1 Check (wenn mehrere Print-Shapes)

6. shop_live    → Live im Shop, VK gesetzt, kaufbar
```
